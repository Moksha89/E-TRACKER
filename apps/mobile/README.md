# etracker-mobile

Expo + React Native + TypeScript app for SVE Expenses.

## Setup

```bash
cd apps/mobile
npm install
npx expo start
```

Press `a` to open Android, `i` for iOS, or scan the QR with Expo Go.

The API base URL is read from `app.json` `expo.extra.apiBaseUrl` and defaults
to `http://localhost:8000`. Override per-environment by setting
`EXPO_PUBLIC_API_BASE_URL`.

## Layout

- `src/api/` — axios client + typed wrappers
- `src/state/` — Redux Toolkit slices (auth, session)
- `src/components/` — small reusable widgets
- `app/` — Expo Router routes (auth flow + main tabs)

## Lint / typecheck

```bash
npm run lint
npm run typecheck
```

## Local Android APK build

The `android/` directory is generated by `expo prebuild` — don't commit it. Build flow:

```bash
cd apps/mobile
npm install
npx expo prebuild --platform android --clean
cd android
./gradlew assembleRelease -x lint
# APK lands at android/app/build/outputs/apk/release/app-release.apk
```

Requires Android SDK 34 + build-tools 34.0.0 + Java 17. Cleartext HTTP is enabled
via `expo-build-properties` because the API is currently served over plain HTTP;
flip `usesCleartextTraffic` to `false` in `app.json` once the API is on HTTPS.
